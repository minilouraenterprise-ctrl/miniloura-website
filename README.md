# Miniloura Website

A modern, aesthetic business website for Miniloura featuring a pink-themed "soft glam" design.

## How to View the Website

### Option 1: Direct File Access (Recommended)
1. Open your file explorer
2. Navigate to: `c:/Users/A/Documents/CascadeProjects/windsurf-project/`
3. Double-click on `index.html`
4. The website will open in your default browser

### Option 2: Browser File Menu
1. Open any web browser (Chrome, Firefox, Safari, Edge)
2. Press `Ctrl+O` (or `Cmd+O` on Mac)
3. Navigate to and select `index.html`
4. Click "Open"

### Option 3: If you have Python installed
```bash
cd c:/Users/A/Documents/CascadeProjects/windsurf-project
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser

## Website Features

- **Soft Glam Pink Theme**: Pastel pink, blush pink, and white color palette
- **Animated Sparkles**: Floating sparkles and shimmer effects
- **Responsive Design**: Works on mobile and desktop
- **Interactive Elements**: Hover effects, smooth scrolling, form validation
- **Four Sections**: Home, About, Product, Contact

## Files Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive features and functionality

## Browser Compatibility

The website works best on modern browsers:
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## Troubleshooting

If the website doesn't display correctly:
1. Make sure all three files (index.html, styles.css, script.js) are in the same folder
2. Try refreshing the page with `Ctrl+F5` to clear cache
3. Check browser console for any error messages (press F12)
